# Star Quest — Kenney UI demo

Самостоятельный проект AdaEngine по структуре Fold: библиотека `StarQuestGame`, приложение
`StarQuest`, каталог `Assets`, тесты и настройки AdaEditor в `.ada/project.json`.

Откройте **папку StarQuest** в AdaEditor и запустите executable **StarQuest**.
Для встроенного Swift Preview откройте `Sources/StarQuestGame/StarQuestView.swift`.
Файлы `Assets/UI/*.ui` открываются в UI Designer. Игра запускается через SwiftPM Run,
а не через Play редактора ECS-сцены: ей не требуется `.ascn` или собственная физика.

На macOS:

```sh
./script/build_and_run.sh
```

Приложение появляется в `dist/StarQuest.app`. Сборка изолирована в `/tmp/starquest-build`;
другую директорию можно задать через `STARQUEST_BUILD_PATH`.

## Сценарий

- **New adventure** начинает сбор пяти звёзд. Каждую можно собрать один раз.
- **Pause**, **Resume** и **Main menu / Continue** сохраняют текущую экспедицию в памяти.
- Сбор всех звёзд открывает экран награды; **Play again** начинает заново.
- **Settings** меняет фон и ширину панели — видно, как работают 9-slice рамки.
- Кнопка **UI / Switch** переключает Swift и `.ui` без потери состояния и прогресса.
- Лучший результат, фон и ширина сохраняются между запусками. Незавершённая экспедиция — только до закрытия приложения.

## Устройство

`StarQuestModel` владеет состоянием, действиями и привязками. `.ui` и Swift используют один экземпляр модели.
Шесть `.ui`-файлов содержат внешний вид экранов; обработчики передаются через `UIBindingContext`.
`NativeQuestScreen` реализует те же экраны обычными AdaUI View.
Изображения в `Assets/Textures` — Kenney UI Pack 2.0, CC0 (см. `License.txt`).

Редактирование `.ui` проверяется после нового запуска; автоматическая перезагрузка файлов здесь не включена.
Для новых `textureButtonStyle` и `cap*` требуется AdaEditor, собранный с текущим AdaUI.

## Тесты

```sh
swift test --scratch-path /tmp/starquest-build
```

Проверяется загрузка настоящих UI-файлов, привязки действий, повторный сбор, пауза,
возобновление, завершение экспедиции и настройки.

## Проверка и ограничение рендерера

На macOS проверены запуск app bundle, начало экспедиции, сбор звезды,
переключение с `.ui` на Swift с сохранением прогресса и завершение до 5/5.

В этом сценарии обнаружено исчезновение неизменившихся элементов при повторном использовании
GPU-геометрии AdaUI. Поэтому оболочка демки использует
`drawingGroup(cachesContents: false)`: отключение кэша локально для её поддерева.
Обычное кэширование остальных приложений не меняется. Общая причина дефекта кэша пока не исправлена.
Полная перерисовка увеличивает работу CPU при изменении интерфейса; это функциональная демка, не бенчмарк.

Редактирование в запущенном UI Designer и касания на iPad в этой проверке не выполнялись.

## Выделение элементов

Кнопки подсвечиваются золотой обводкой при наведении и фокусе; при нажатии обводка усиливается.
Отключённые кнопки не подсвечиваются.
В UI Designer у `textureButtonStyle` доступны `selectionEffect` и `selectionColor` (RGBA).
В Swift эффект включается через `TextureButtonStyle(..., selectionEffect: true, selectionColor: ...)`.
